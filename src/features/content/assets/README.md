# Content assets

Embedded in the server binary (`include_bytes!`) and served from `/e/...`.

- `icons/*.png`: social link icons, 96×96. Network glyphs are from Simple Icons (CC0 1.0, https://simpleicons.org); the website and email glyphs are from Lucide (ISC license, https://lucide.dev). Styles: `color` (network color circle), `dark`, `light` and `white` (for dark backgrounds).
- `placeholder-*.png`: neutral sample images used by the starter templates until you add your own.
- `NotoSans-Bold-subset.ttf`: Noto Sans Bold cut down to printable ASCII, for countdown timer images. SIL Open Font License 1.1 (`OFL-1.1.txt`), copyright Google LLC / The Noto Project Authors.
